# Stellar Pathways

Stellar Pathways is an astronomy-oriented repository aimed at tackling *tacit knowledge*. Tacit knowledge is knowledge that is extremely hard to articulate, and thus is learned through personal experience rather than formal education. 

This issue of tacit knowledge is extremely prevalent in physics and astronomy as a whole, and this repository seeks to tackle this issue head-on. There are so many tools students learn but are never formally taught in physics/astronomy, which is understandable because it becomes challenging to incorporate all of these into a curriculum, and if the students don't have any sort of advisor to guide them, they have to learn it themselves. Thus, we aim to provide the tools required for students in a singular, easy-to-follow location, so they can have a place to access tangible resources to learning these skills. This includes/will include making professional CVD-friendly plots, model fitting, using Linux and the command line, documenting code, Git/GitHub usage, MPI/HPC tools, $\LaTeX$, and more!

The name for this repository was courtesy of another astronomer (prefers to remain anonymous). It is a play on words for general stellar pathways (like stellar evolution on an HR diagram), while also having this repository be a "pathway" for beginning astronomers to be "stellar" in their future work!

Designed by Neil Ghugare, Intended for [PHYSDepot](https://physdepot.org).

As of 10/17/2026, this repository is still being *actively worked on and developed*.
